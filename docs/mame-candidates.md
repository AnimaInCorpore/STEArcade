# MAME candidates with hardware like the ported games

Generated 2026-10-29 from `mame -listxml` (MAME 0.289). 737 games, one entry per game (already-ported games left out), sorted by popularity. Each game is shown with its World set where MAME has one, else the US set (including official US licensee releases such as Midway, Atari, Centuri, Stern or Williams), else the MAME parent; separate MAME parents of the same game (other hardware revisions, renamed releases) are merged into one row and listed under *Same game in MAME*.

**Popularity** = number of official region, licensee and revision sets MAME has for the game (bootlegs and hacks not counted; merged parents added up). Popular games were relicensed and revised most; it is a proxy, not play statistics.

**Selection:** working (good/imperfect) parent sets up to 1991 with a raster screen, coin inputs, tile/sprite graphics ROMs (bitmap-only machines and machines with graphics/DSP coprocessors left out), a main CPU of a ported family (Z80; 6809/HD6309/KONAMI-1; V30; 68000/68010 up to 10 MHz) within the ported clock and program ROM range, graphics ROMs up to 2.3 MB, and only sound chips the ports already handle (AY-3-8910, YM2203, YM3526/YM3812, YM2151, SN76489, VLM5030, MSM5205, DAC, Namco WSG, POKEY, TMS5220, samples, plus OKI MSM6295 and the 2A03). Gambling machines are filtered by name and driver; bootlegs and hacks are left out.

6809 clocks are the internal (E) clock. *Program* = main CPU ROM; *Gfx* = all tile, sprite and character ROMs. *Closest port* = ported game with the most similar CPU, clock, ROM size, sound chips and driver.
